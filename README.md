# IKEA Customer Analytics – Customer Segmentation & RFM Analysis

## 1. Project Overview

This project focuses on analyzing retail transaction data using SQL, Python, and Power BI, with IKEA as a fictional business context.

The main objective is to understand customer purchasing behavior, analyze revenue performance, and identify valuable customer segments using RFM (Recency, Frequency, and Monetary) analysis.

## 2. Disclaimer

This is an independent educational portfolio project. IKEA is used only as a fictional business context for analysis and dashboard design. This project is not affiliated with or endorsed by IKEA.

The analysis uses publicly available Online Retail and Online Retail II datasets from the UCI Machine Learning Repository.

## 3. Business Problem

Understanding customer purchasing behavior is important for identifying valuable customers, improving customer retention, and monitoring business performance.

This project analyzes retail transaction data to identify customer purchasing patterns, evaluate revenue contribution, and understand different customer segments.

## 4. Business Questions

- Which customer segments contribute the most revenue?
- How many customers belong to each segment?
- Which customers generate the highest business value?
- How does revenue change over time?
- Which customer segments show signs of reduced purchasing activity?
- How do Recency, Frequency, and Monetary values differ across customer segments?
- Which customer segments should the business focus on for better customer retention?

## 5. Dataset Sources

The project uses publicly available datasets from the UCI Machine Learning Repository:

- Online Retail Dataset
- Online Retail II Dataset

These datasets contain retail transaction details such as invoice numbers, product descriptions, quantities, unit prices, customer IDs, and country information.


## 6. Tools & Technologies

- **Oracle SQL Developer** – Data querying and analysis.
- **Python** – Data processing and RFM analysis.
- **Power BI** – Interactive dashboard development.
- **DAX** – Measures and business calculations.
- **Excel** – Data inspection and preparation.

## 7. Project Workflow

1. Collected and explored the retail transaction datasets.
2. Cleaned and prepared the data for analysis.
3. Used Oracle SQL Developer to perform data querying and analysis.
4. Used Python to calculate RFM scores and segment customers.
5. Developed interactive dashboards using Power BI.
6. Analyzed customer segments, revenue performance, and purchasing trends.
